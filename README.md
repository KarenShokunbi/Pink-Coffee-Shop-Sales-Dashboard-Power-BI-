# Pink-Coffee-Shop-Sales-Dashboard-Power-BI-
This project presents an interactive Sales Dashboard built using Power BI, designed to analyze and visualize the performance of a coffee shop business operating in the USA.  The dashboard provides actionable insights into revenue, customer behavior, product performance, and geographic trends using transactional sales data from 2023 - 2024.
## Objectives
Analyze overall business performance (Revenue, Transactions, Customers)
Identify top-performing products and categories
Track sales trends over time (daily & monthly)
Evaluate regional (location-based) revenue distribution
Support data-driven decision-making
## Dataset Information
Source: Proprietary dataset provided by the company
Format: CSV
Time Period: 2023 – 2024
Geographical Scope: United States
Key Fields in Dataset:
Transaction ID
Date (Daily granularity)
Product Category (Coffee, Tea, Pastry)
Product Name
Quantity Sold
Revenue
Customer ID
Customer Name
Location (State-based)
## Tools and Technologies
Power BI – Data modeling, visualization, and dashboard creation
Power Query – Data cleaning and transformation
DAX (Data Analysis Expressions) – Measures and calculated fields
CSV Data Source – Raw dataset
## Key Metrics
The dashboard tracks the following core metrics:
Total Revenue: 675K
Total Transactions: 300
Total Customers: 50
Total Quantity Sold: 881
## Key Insights
Coffee dominates revenue contribution, making it the core business driver
Mid-week sales spikes suggest strong weekday demand patterns
A small customer base (50 customers) generates significant revenue → indicates high-value customers
Certain states significantly outperform others, suggesting regional demand concentration
Pastry and tea contribute less but offer opportunities for upselling and bundling strategies
## Interactivity
The dashboard includes:
Month-based filtering (January–December)
Year selection (2023 vs 2024)
Visual cross-filtering across charts
## How to Use
Download the .pbix file from this repository
Open using Power BI Desktop
Use the filters on the left panel to explore:
Monthly performance
Yearly comparison
Hover over visuals for deeper insights
